## 고음(High Notes)

- [과학적 상세 문서](high-note-scientific-explanation.md)
- [ELI5 시각 가이드](high-note-eli5.html)
- [시각 가이드 이미지 프롬프트](assets/high-note-eli5/PROMPTS.md)

고음 가이드는 음높이와 음색, 성구, 공명, 장르별 목표, 연습과 건강을 분리해 설명한 뒤 하나의 조절 문제로 다시 연결합니다. 시각 가이드는 외부 웹 라이브러리 없이 동작하며, 생성 이미지는 실제 의료 영상이나 측정 자료가 아닌 교육용 모식도입니다.

## 발성(Voice Production / Phonation)

- [과학적 상세 문서](phonation-scientific-explanation.md)
- [ELI5 시각 가이드](phonation-eli5.html)
- [시각 가이드 이미지 프롬프트](assets/phonation-eli5/PROMPTS.md)

발성 가이드는 목소리를 뇌–호흡–성대–성도–감각 피드백의 닫힌 시스템으로 설명합니다. 음향 효율·주관적 편안함·조직 안전성처럼 흔히 한 덩어리로 취급되는 개념을 분리하고, 말과 여러 노래 장르의 목표, 측정법의 한계, 훈련과 건강 의사결정까지 연결합니다. 시각 가이드는 외부 웹 라이브러리 없이 동작하며, 생성 이미지는 실제 의료 영상이나 측정 자료가 아닌 교육용 모식도입니다.
